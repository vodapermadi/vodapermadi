Berlayar dari pulau RPL angkatan 2023, saya adalah seorang *developer* yang terus mengasah *Haki* dalam dunia *software engineering*. Dengan kapal kesayangan (ThinkPad T440 veteran) yang selalu siap menerjang badai *error*, saya pantang menyerah menebas *bug* seperti **Zoro** yang tak pernah mundur dari pertarungan! ⚔️

Sambil *ngoding*, saya mengumpulkan *Belly* 💰 demi target membeli tunggangan besi (motor) agar bisa menjelajah rute petualangan baru di jalanan.
